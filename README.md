# Securing-a-networked-system-with-Public-Key-Infrastructure
Cyber Security Project 
Projects:
PKI & TLS Security Implementation on Linux
- Set up Ubuntu Linux on VirtualBox and configured
  a full Public Key Infrastructure (PKI) with
  Root CA, Sub CA, and SSL certificates
- Configured Apache web server with HTTPS,
  DNS server (BIND9), UFW firewall, and OpenSSH
- Implemented IDS using Snort and demonstrated
  SYN flood attack detection
- Tools: Linux, Bash, OpenSSL, Apache, BIND9,
  UFW, Snort, VirtualBox
